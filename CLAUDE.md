
# Flujo de trabajo (2 Macs: Pro + Air)

Este proyecto se sincroniza por Git entre dos Macs. iCloud NO sincroniza el codigo.

**Al iniciar una sesion en este proyecto:** ejecuta `git pull` para traer lo ultimo de GitHub antes de hacer cualquier cambio.

**Al terminar la sesion o un bloque de trabajo:** ejecuta `git add .`, luego `git commit -m "<resumen de lo hecho>"`, y luego `git push` para subir a GitHub.

Haz esto de forma proactiva sin que el usuario lo pida.
